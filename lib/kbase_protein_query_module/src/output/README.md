# Output Manager

This module handles the organization and saving of outputs generated by the KBase Protein Query Module.

## Structure

The output directory structure is organized as follows:

```
outputs/
├── metadata/
│   ├── run_metadata.json    # Global run metadata (config, summary, etc.)
│   └── process_info.json    # Execution stats (timings, stages)
└── analysis/
    ├── [analysis_name]/     # Directory for each analysis module
    │   ├── results.json     # Main analysis results
    │   ├── summary.txt      # Human-readable summary
    │   └── [other_files]    # Analysis-specific outputs (plots, tables, etc.)
    └── ...
```

## Usage

The `OutputManager` is typically initialized by the `WorkflowOrchestrator` and passed to analysis modules.

```python
from kbase_protein_query_module.src.output.output_manager import OutputManager

# Initialize
manager = OutputManager(base_output_dir="/path/to/output", run_id="my_run")

# Save analysis results
manager.save_analysis_output(
    analysis_name="network_analysis",
    result={"nodes": [...], "edges": [...]},
    output_dir=None # Managed automatically
)

# Save run metadata
manager.save_metadata(
    config={...},
    analyses_run=["network_analysis"],
    summary="Run completed successfully"
)
```
